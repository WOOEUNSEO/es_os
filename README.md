# es OS

브라우저 안에 있는 나만의 작은 컴퓨터예요. 맥처럼 깔끔한 글래스 디자인과 부드러운 모션으로 만들었고, GitHub Pages에서 무료로 동작해요.

## 들어 있는 앱

| 앱 | 할 수 있는 것 |
| --- | --- |
| **Finder** | 폴더 만들기·이름 변경·복제·이동(드래그)·휴지통, 아이콘/목록 보기, 검색, 폴더 색상, 태그, 내 컴퓨터 파일 가져오기 |
| **메모** | 텍스트 파일 작성과 편집 (자동 저장), 메모 검색 |
| **사진** | 사진 가져오기, 크게 보기, 넘겨 보기, 배경화면으로 지정 |
| **캘린더** | 월 보기, 날짜별 일정 추가·삭제, 색상 지정 |
| **시스템 설정** | 이름, 라이트/다크/자동 테마, 강조 색상, 배경화면, 백업 내보내기·가져오기, 초기화 |

그 밖에 잠금 화면, 메뉴 막대, 확대되는 Dock, 날짜·할 일 위젯, 검색창(Ctrl/⌘ + K, 계산 가능)이 있어요.

## 데이터 저장

모든 파일과 설정은 **사용하는 브라우저의 IndexedDB**에 저장돼요. 서버가 없어서 다른 기기와는 공유되지 않아요. 시스템 설정 → 데이터에서 백업 파일을 내려받아 두면 다른 브라우저에서도 그대로 불러올 수 있어요.

## 구조

```
index.html
css/style.css
js/
  main.js         시작
  store.js        파일 시스템, 일정, 할 일, 저장
  defaults.js     처음 들어 있는 파일
  wm.js           창 관리 (드래그, 크기 조절, 최소화, 확대)
  shell.js        메뉴 막대, Dock, 데스크탑, 위젯, 검색, 잠금 화면
  ui.js           메뉴, 대화상자, 드래그 앤 드롭, 파일 가져오기
  icons.js        아이콘
  appearance.js   테마, 배경화면
  apps/           finder, notes, photos, calendar, settings
```

빌드 과정 없이 순수 HTML/CSS/JavaScript(ES 모듈)로 되어 있어요. 로컬에서 볼 때는 폴더에서 `python3 -m http.server` 를 실행하고 `http://localhost:8000` 을 열면 돼요.
